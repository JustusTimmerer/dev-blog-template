This is a sample post. It shows the article layout with sections, a table, a figure, a quote and a code block. The contents list on the left follows your position on the page.

## What this template gives you

Each post is one Markdown file. The build turns it into a static page. No database and no server code are necessary, so any web space can host the result.

Readers choose a theme, a text size, a page width and a font. The site remembers the choice in the browser.

## How a post is built

Each post starts with a small block of fields:

```yaml
title: My post
description: One sentence for lists and search engines.
date: 2026-10-26
tags: [tooling]
series: example-series
part: 3
featured: true
```

![From idea to release](../../../assets/sample-figure.svg "From idea to release")

### Series

A series groups short posts about one topic. Each part links to the other parts. The [series page](/series/example-series/) lists all parts in order.

### Translations

A file with the same name in another language folder is the translation. Without a translation, the reader sees the original text and a short note.
